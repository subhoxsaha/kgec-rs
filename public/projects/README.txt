KGEC ROBOTICS SOCIETY - FLAGSHIP PROJECT MEDIA STORAGE
===========================================================
Drop robot build and project photos directly into this folder:
/public/projects/

HOW IMAGES ARE MATCHED AUTOMATICALLY:
-------------------------------------
1. By Project ID:
   Save your image with the project ID, for example:
   - vajra-30.jpg
   - apex-rover-v3.png
   - krs-agastya.webp
   - garuda-uav-x.jpg
   The website will automatically load and display it for that project!

2. Supported formats:
   .jpg, .jpeg, .png, .webp, .svg

3. Direct JSON edits:
   You can also edit /public/data/projects.json directly.
