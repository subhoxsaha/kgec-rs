Team & Mentors Photos Directory
=================================
Drop team member profile pictures (WebP, JPG, JPEG, PNG) directly into this folder (/public/team/).

Auto-detection by Member ID:
1. Name your image file with the member's unique ID, for example:
   - /public/team/ld-3.jpg (or .png, .webp) for Lead member with "id": "ld-3"
   - /public/team/tb-1.webp for Teacher Body member with "id": "tb-1"
   - /public/team/sb-2.jpg for Student Body member with "id": "sb-2"
2. The website will automatically detect and link the picture by ID. No other manual URL entry required!
3. If no image matching the ID is placed here, an elegant default avatar placeholder (/team/default-avatar.svg) will be used.
